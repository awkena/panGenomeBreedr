# Query genotypes for specific variant IDs (local)

Extracts complete genotype call records along with specified variant
metadata properties for an explicit vector list of unique variant
identifiers. Automatically resolves and unpacks internal array-packed
list formats seamlessly into standard wide columns.

## Usage

``` r
query_genotypes(
  con,
  variant_ids,
  variant_id_col = "variant_id",
  variants_table = "variants",
  genotypes_table = "genotypes",
  meta_data = NULL
)
```

## Arguments

- con:

  A DBI connection object to the local database generated by
  [`connect_local_db()`](https://awkena.github.io/panGenomeBreedr/reference/connect_local_db.md).

- variant_ids:

  A character vector of unique variant identifiers to look up (e.g.,
  `c("SNP_Chr05_75104557")`).

- variant_id_col:

  A character value specifying the primary key column name for variant
  IDs. Defaults to `"variant_id"`.

- variants_table:

  A character value specifying the name of the variants reference table
  view. Defaults to `"variants"`.

- genotypes_table:

  A character value specifying the name of the genotype call data table
  view. Defaults to `"genotypes"`.

- meta_data:

  A character vector of metadata columns (e.g., `"chrom"`, `"pos"`,
  `"ref"`) to include from the variants table. If `NULL`, returns all
  available schema fields.

## Value

A data frame containing mapped metadata tracking columns alongside
individual sample genotype calls formatted in a structured
variants-by-samples matrix.

## Examples

``` r
if (FALSE) { # \dontrun{
# Load the package
library(panGenomeBreedr)

# Connect to the database pipeline
con <- connect_local_db(folder_path = "~/Desktop/curated_sorghum_variant_resource")

# Extract all sample genotypes for an explicit list of target marker strings
target_markers <- c("INDEL_Chr05_75104541", "SNP_Chr05_75104557")
marker_matrix <- query_genotypes(con = con, 
                                 variant_ids = target_markers,
                                 meta_data = c("chrom", "pos", "ref", "alt", "variant_type"))

# Safely close out the database connection
disconnect_local_db(con)
} # }
```
