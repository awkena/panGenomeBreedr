# Count the distribution of variant types in the database (local)

Queries the database to calculate a global summary of how many variants
exist for each distinct structural classification type (e.g., SNP,
INDEL).

## Usage

``` r
count_variant_types(con)
```

## Arguments

- con:

  A DBI connection object to the local database generated by
  [`connect_local_db()`](https://awkena.github.io/panGenomeBreedr/reference/connect_local_db.md).

## Value

A data frame containing two columns: `variant_type` (the structural
classification group name) and `n` (the total count of variants in that
group).

## Examples

``` r
if (FALSE) { # \dontrun{
# Load the package
library(panGenomeBreedr)

# Connect to the database pipeline
con <- connect_local_db(folder_path = "~/Desktop/curated_sorghum_variant_resource")

# Get the breakdown counts of SNPs vs INDELs across the resource
type_counts <- count_variant_types(con)

# Safely close out the database connection
disconnect_local_db(con)
} # }
```
