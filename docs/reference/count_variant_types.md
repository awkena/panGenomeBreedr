# Count the distribution of variant types in the database (local)

Count the distribution of variant types in the database (local)

## Usage

``` r
count_variant_types(con, variants_table = "variants")
```

## Arguments

- con:

  A DBI connection object to the local database generated by
  [`connect_local_db()`](https://awkena.github.io/panGenomeBreedr/reference/connect_local_db.md).

- variants_table:

  Character. The name of the table containing variant metadata. Defaults
  to "variants".

## Value

A data frame containing two columns: `variant_type` (the structural
classification group name) and `n` (the total count of variants in that
group).

## Examples

``` r
if (FALSE) { # \dontrun{
# Load the package
library(panGenomeBreedr)

# Define the path to the curated_sorghum_variant_resource folder
my_db_folder <- "~/Desktop/curated_sorghum_variant_resource"

# Establish the connection
con <- connect_local_db(folder_path = my_db_folder)

# Get the breakdown counts of SNPs vs INDELs
count_variant_types_result <- count_variant_types(con)
print(count_variant_types_result)

# Disconnnect at the end of the session.
disconnect_local_db(con)
} # }
```
