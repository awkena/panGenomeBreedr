# Extract regional variants filtered by allele frequency (local)

Queries a specific genomic coordinate region to extract genotype
matrices, computes population-level alternate allele frequencies on the
fly, and returns a subset of variants falling strictly within the
specified minimum and maximum frequency thresholds.

## Usage

``` r
query_by_af(
  con,
  min_af = 0,
  max_af = 1,
  chrom = NULL,
  start = NULL,
  end = NULL
)
```

## Arguments

- con:

  A DBI connection object to the local database generated by
  [`connect_local_db()`](https://awkena.github.io/panGenomeBreedr/reference/connect_local_db.md).

- min_af:

  Numeric. Minimum alternate allele frequency threshold for filtering.
  Must fall between 0 and 1. Defaults to `0`.

- max_af:

  Numeric. Maximum alternate allele frequency threshold for filtering.
  Must fall between 0 and 1. Defaults to `1`.

- chrom:

  A character value specifying the target chromosome name (e.g.,
  `"Chr05"`).

- start:

  Integer. Optional start coordinate for the target window region.

- end:

  Integer. Optional end coordinate for the target window region.

## Value

A data frame of variants passing the frequency thresholds within the
defined region, tracking their coordinates, calculated reference allele
frequencies (`ref_af`), and alternate allele frequencies (`alt_af`).

## Examples

``` r
if (FALSE) { # \dontrun{
# Load the package
library(panGenomeBreedr)

# Connect to the database pipeline
con <- connect_local_db(folder_path = "~/Desktop/curated_sorghum_variant_resource")

# Query a specific locus window and filter for common variants (MAF >= 5%)
regional_af_vars <- query_by_af(con = con,
                                min_af = 0.05,
                                max_af = 0.95,
                                chrom = "Chr05",
                                start = 75104537,
                                end = 75106403)

# Safely close out the database connection
disconnect_local_db(con)
} # }
```
