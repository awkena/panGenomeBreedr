# Filter genotypes by multiple sample metadata criteria (local)

Filter genotypes by multiple sample metadata criteria (local)

## Usage

``` r
query_geno_by_meta(con, genotype_matrix, genotype_start_col, filters)
```

## Arguments

- con:

  A DBI connection object to the local database generated by
  [`connect_local_db()`](https://awkena.github.io/panGenomeBreedr/reference/connect_local_db.md).

- genotype_matrix:

  A data frame or matrix where rows are variants and columns include
  variant metadata followed by sample genotypes.

- genotype_start_col:

  An integer specifying the column index where sample genotype calls
  begins.

- filters:

  A named list of metadata criteria to filter samples by. Names must
  match metadata schema columns, and values are the allowed entries.
  Example:
  `list(population = "Gates", countryorigin = c("Ethiopia", "Ghana", "Togo"))`

## Value

A data frame containing the filtered genotype matrix with recalculated
allele metrics for the sub-population. Returns an empty data frame if no
samples match all combined criteria.

## Examples

``` r
if (FALSE) { # \dontrun{
# Load the package
library(panGenomeBreedr)

# Define the path to the curated_sorghum_variant_resource folder
my_db_folder <- "~/Desktop/curated_sorghum_variant_resource"

# Establish the connection
con <- connect_local_db(folder_path = my_db_folder)

# Define filtering criteria
my_filters <- list(
  population = "Gates",
  countryorigin = c("Ethiopia", "Ghana", "Togo")
)

# Extract the full genotype matrix first for the genomic region
query_db_result <- query_db(
  con = con,
  table_name = "genotypes",
  chrom = "Chr05",
  start = 75104537,
  end = 75106403
)

# Get filtered genotypes matrix
query_geno_by_meta_result <- query_geno_by_meta(
  con = con,
  genotype_matrix = query_db_result,
  genotype_start_col = 11,
  filters = my_filters
)
print(query_geno_by_meta_result)

# Disconnect at the end of your session
disconnect_local_db(con)
} # }
```
