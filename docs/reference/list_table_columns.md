# Get table schema details (local)

Get table schema details (local)

## Usage

``` r
list_table_columns(con, table_name = c("variants", "annotations", "genotypes"))
```

## Arguments

- con:

  A DBI connection object to the local database generated by
  [`connect_local_db()`](https://awkena.github.io/panGenomeBreedr/reference/connect_local_db.md).

- table_name:

  A character value specifying the name of the table to inspect. Must be
  one of `"variants"`, `"annotations"`, or `"genotypes"`.

## Value

A data frame containing the schema details of the target table,
including column names and data types.

## Examples

``` r
if (FALSE) { # \dontrun{
# Load the package
library(panGenomeBreedr)

# Define the path to the curated_sorghum_variant_resource folder
my_db_folder <- "~/Desktop/curated_sorghum_variant_resource"

# Establish the connection
con <- connect_local_db(folder_path = my_db_folder)

# Inspect the schema layout of the variants table
column_schema <- list_table_columns(con, table_name = "variants")

# Disconnect at the end of your session
disconnect_local_db(con)
} # }
```
