# Get summarized functional annotations, impacts and variant types for a genomic region (local)

Get summarized functional annotations, impacts and variant types for a
genomic region (local)

## Usage

``` r
query_ann_summary(
  con,
  chrom,
  start,
  end,
  annotations_table = "annotations",
  variants_table = "variants"
)
```

## Arguments

- con:

  A DBI connection object to the local database generated by
  [`connect_local_db()`](https://awkena.github.io/panGenomeBreedr/reference/connect_local_db.md).

- chrom:

  A character value specifying the target chromosome name (e.g.,
  `"Chr05"`).

- start:

  Integer. Start coordinate for the target window region.

- end:

  Integer. End coordinate for the target window region.

- annotations_table:

  A character value specifying the name of the annotations reference
  table. Defaults to `"annotations"`.

- variants_table:

  A character value specifying the name of the variants reference table.
  Defaults to `"variants"`.

## Value

A list object containing three summarized summary data frames:

- `annotation_summary`: Counts of distinct functional mutations grouped
  by type.

- `impact_summary`: Counts of predicted functional impacts grouped by
  type.

- `variant_type_totals`: Entire marker breakdown counts across the
  defined coordinate window.

## Examples

``` r
if (FALSE) { # \dontrun{
# Load the package
library(panGenomeBreedr)

# Define the path to the curated_sorghum_variant_resource folder
my_db_folder <- "~/Desktop/curated_sorghum_variant_resource"

# Establish the connection
con <- connect_local_db(folder_path = my_db_folder)

# Extract functional distribution summaries across a specific gene locus window
query_ann_summary_result <- query_ann_summary(con = con,
                                        chrom = "Chr05",
                                        start = 75104537,
                                        end = 75106403)
print(query_ann_summary_result)


# Disconnect at the end of your session
disconnect_local_db(con)
} # }
```
