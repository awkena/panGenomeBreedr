# Get variant statistics from the database (local)

Computes summary statistics for variants across chromosomes, including
total counts, genomic ranges (minimum and maximum positions), and
optionally distinct annotated variant counts.

## Usage

``` r
variant_stats(con, include_annotations = TRUE)
```

## Arguments

- con:

  A DBI connection object to the local database generated by
  [`connect_local_db()`](https://awkena.github.io/panGenomeBreedr/reference/connect_local_db.md).

- include_annotations:

  A logical value indicating whether to include statistics for the
  annotations table. Defaults to `TRUE`.

## Value

A data frame of variant statistics grouped by chromosome.

## Examples

``` r
if (FALSE) { # \dontrun{
# Load the package
library(panGenomeBreedr)

# Connect to the database
con <- connect_local_db(folder_path = "~/Desktop/curated_sorghum_variant_resource")

# Get variant statistics across all chromosomes
stats_df <- variant_stats(con, include_annotations = TRUE)

# Safely close the connection
disconnect_local_db(con)
} # }
```
