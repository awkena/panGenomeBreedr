# Get the current database API endpoint URL

Get the current database API endpoint URL

## Usage

``` r
get_api_url()
```

## Value

The character string of the active API URL.

## Examples

``` r
if (FALSE) { # \dontrun{
# Load the package
library(panGenomeBreedr)

# Get the current API endpoint URL
get_api_url()

} # }
```
