# Query genotypes filtered by sample metadata attributes (local)

Retrieves genotype calls for a specific genomic region, but restricts
the wide-format column outputs to a subset of samples defined by
matching metadata attributes (e.g., isolating variants only for specific
countries of origin, breeding populations, or genetic clusters).

## Usage

``` r
query_by_metadata(con, chrom, start = NULL, end = NULL, meta_col, meta_value)
```

## Arguments

- con:

  A DBI connection object to the local database generated by
  [`connect_local_db()`](https://awkena.github.io/panGenomeBreedr/reference/connect_local_db.md).

- chrom:

  Character. The target chromosome name (e.g., `"Chr05"`).

- start:

  Integer. Optional start coordinate for the target window region.

- end:

  Integer. Optional end coordinate for the target window region.

- meta_col:

  Character. The metadata schema column to filter samples by (e.g.,
  `"countryorigin"`).

- meta_value:

  Character or Numeric. The explicit value attribute to match within
  `meta_col` (e.g., `"Mali"`).

## Value

A wide-format data frame (variants x filtered samples) tracking core
variant properties alongside matching genotype calls.

## Examples

``` r
if (FALSE) { # \dontrun{
# Load the package
library(panGenomeBreedr)

# Connect to the database pipeline
con <- connect_local_db(folder_path = "~/Desktop/curated_sorghum_variant_resource")

# Get genotypes for a specific gene region, but restrict columns to samples from Mali
mali_genotypes <- query_by_metadata(con = con,
                                    chrom = "Chr05",
                                    start = 75104537,
                                    end = 75106403,
                                    meta_col = "countryorigin",
                                    meta_value = "Mali")

# Safely close out the database connection
disconnect_local_db(con)
} # }
```
